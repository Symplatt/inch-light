# 3.12.3+64 性能调整与验证

日期：2026-10-21。3.12.2 已完成正式 GitHub 发布后才开始本轮修改。

## 备份与范围

代码修改前在手机设置执行导出备份，成功保存 inch-light-2026-10-21_21-24-45_535.json（184324 字节）。保持功能、界面布局、格式按钮、富文本数据格式、键盘显示条件、350 毫秒保存延迟和撤回重做行为；没有更换输入法或调整系统键盘动画。

## 排查到的同步工作

- 编辑控制器同时通知文字、格式与选区变化，原处理会在每次通知中把整篇文档序列化为 JSON，即使仅移动光标。
- 元信息每次页面重建都会新建记录对象并重新计算全文字数。键盘尺寸变化导致多次重建时，重复遍历长笔记。
- 语法栏构建时逐按钮查询选区格式，同一组选区在一次构建中查询 17 次。
- 键盘高度变化时，父页面重新创建 QuillEditor 配置，正文随之重新构建；文档自身的布局配置没有随键盘高度变化。

## 实际修改

1. 在当前已固定版本的 Quill Document 中增加只读 revision，每次成功 compose 同步递增。光标、焦点与输入法组合范围不递增，不写入 Delta 或备份。使用同步计数而非异步 changes 事件，确保控制器通知发生时缓存已经失效。
2. 新增 JournalEditorCache，依据文档对象与 revision 缓存 Delta JSON；依据标题、标签、加粗与正文版本缓存撤回快照。真正的输入、格式变化和文档替换仍会立即更新。
3. 元信息字数按正文数据版本缓存，继续使用原有字数计算算法，包括 Unicode 字符和表格内容。
4. 语法栏每次构建只查询一次选区格式，各按钮共享结果；点击按钮时仍按最新选区执行操作。
5. 正文编辑组件按文档对象、焦点、嵌入行状态、表格选区、表格自动聚焦与页面样式参数复用。键盘高度只改变外层可视区域；Quill 自身仍接收控制器和焦点事件。文档替换、字号、间距、表格选区或焦点改变时会更新配置。

## 可复现的受控对照

使用同一台电脑、相同 Flutter 测试模式、相同 420×900 视口和 350 段长笔记（1050 个 Delta 操作），分别运行未修改的 3.12.2 与 3.12.3 各三次。基准源码保存在 `tool/editor_performance_benchmark_test.dart`，执行 `flutter test --no-pub tool/editor_performance_benchmark_test.dart` 可复测当前版本；通过 `PERF_OUTPUT` 环境变量指定 JSON／截图输出文件前缀。每次执行相同的进入编辑、35 次光标移动和 12 次键盘高度变化，以下取三轮结果的中位数。

这些数值测量 Flutter 框架处理与页面重建，不包括真实 Android 输入法进程启动、系统键盘动画或端到端触摸延迟，不能解释为手机键盘整体快了同样百分比。

| 指标 | 3.12.2 | 3.12.3 | 下降 |
| --- | --- | --- | --- |
| 进入编辑并完成键盘显示请求所在帧 | 134.74 ms | 119.86 ms | 11.0% |

| 键盘高度变化时的页面重建 | 64.84 ms | 31.26 ms | 51.8% |

语法栏选区格式查询次数由每次构建 17 次降到 1 次。三轮原始测量保存在 build/v3123-performance-summary.json 与对应日志中，不作为源码提交。
