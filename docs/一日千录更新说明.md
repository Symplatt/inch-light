# 一日千录

## 本次改动

- 名称改为一日千录；图标使用内置图片生成工具生成，白底黑色毛笔字，上排「一日」、下排「千录」。源图：`assets/icon.png`。提示词要求：纯白不透明背景、准确的四字 2×2 排版、自然黑色毛笔笔触、四周留白、无印章和装饰。
- 待办作为启动首页，底部包含待办、记录、时历。
- 记录：按下右下角加号捕获时间；Markdown 编辑、三级标题、加粗、斜体、列表和预览；按日分组，跨日浅灰分隔，每条记录独立圆角卡片。
- 待办：截止不足或等于 24 小时为黄色，逾期为红色；合集显示所有未完成事项中最近的截止日期；长按合集可完成或删除其中全部事项；长按普通事项可置顶、置底、恢复默认排序或编辑。只在选择位置后显示小图标。
- 普通事项完成超过 24 小时后，在应用运行、启动或恢复前台时清理；每日打卡保持原来的每日重置，不会被当作普通事项删除。历史数据缺少完成时间的事项保留，避免误删。
- 时历：上部「倒计年月」按绝对日期计时，下部「时日周期」支持每天、每周、每月、每年。全天在 00:00 提醒，也可选具体时分。月末日期在短月份取最后一天，随后恢复原日；闰年 2 月 29 日在平年取 2 月 28 日。

## 数据兼容

保留应用包名、原有本地存储键、任务类型枚举序号和 JSON 字段。新增 `journal_entries`、`calendar_countdowns`、任务的 `isBottom`、周期的 `allDay`。旧备份缺少的新字段采用默认值，缺少的新数据区段保留当前内容。导出仍为原有 JSON 对象结构。导入先解析全部区段，格式错误不会部分覆盖数据。

## 提醒说明

Android 和 iOS 使用系统本地通知，需允许通知权限；其他平台保留数据和倒计时界面，目前不提供后台系统提醒。Android 还会申请精确闹钟权限；拒绝时回退到非精确提醒并在时历页提示。系统省电策略可能影响提醒送达。

为遵守系统通知数量限制，Android 安排最近 450 次，iOS 安排最近 60 次；时历页显示已安排到的日期。每次打开、回到前台、跨日和修改时历时自动续排。若长期不打开应用超过显示的安排期限，需要再次打开以续排。

## 验证

测试覆盖旧备份兼容、新数据往返、坏数据不覆盖、超时清理、合集批量操作隔离、置底排序、月末/闰年周期、待办首页和记录按打开时刻打时间戳。系统锁屏提醒仍需在实际设备上验证。
