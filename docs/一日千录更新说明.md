# 版本说明

当前使用说明见 [README](../README.md)，按版本整理的更新记录见 [CHANGELOG](../CHANGELOG.md)。

3.2.0 提供待办、记录、时历和设置；历史纯文本记录自动恢复，富文本、标签、表格及记录合集、置顶、置底及标题字重均支持本地保存和 JSON 备份。记录使用横向合集导航，默认合集承接旧版零散笔记。现有待办数据的类型编号、存储键和 JSON 字段保持兼容。

3.2.0 增加合集删除和 Android 笔记长图导出，调整列表、引用及标题间距，支持软件键盘行内 Markdown 快捷渲染；表格在下方连续按两次退格删除。合集不再置顶，合集 Markdown 导出直接拼接。
