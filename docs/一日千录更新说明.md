# 版本说明

当前使用说明见 [README](../README.md)，按版本整理的更新记录见 [CHANGELOG](../CHANGELOG.md)。

3.3.0 提供待办、记录、时历和设置；历史纯文本记录自动恢复，富文本、标签、表格及记录合集、置顶、置底及标题字重均支持本地保存和 JSON 备份。记录使用横向合集导航，默认合集承接旧版零散笔记。现有待办数据的类型编号、存储键和 JSON 字段保持兼容。

3.3.0 修复合集 Markdown 标题粘连，长图包含时间、字数与标签；新增一分钟内逐条计时的滑动删除恢复、上标与下标，补全行内代码导出。笔记开头空行可一次退格清除。换行时页面跟随光标，避免键盘及语法栏遮挡。调整合集弹窗、导航对齐、位置与操作图标、列表基线及待办倒计时样式；标签在输入与观看模式中始终右起第二，首页及合集页依次为添加合集、导出。
