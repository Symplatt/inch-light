# 版本说明

当前使用说明见 [README](../README.md)，更新记录见 [CHANGELOG](../CHANGELOG.md)。

3.6.0 保持已有待办、记录、表格、合集和 JSON 备份格式兼容，保留 3.5.0 合并的 3.4 系列功能。

语法栏增加下划线并调整分隔线位置；正文之后 H1／H2／H3 上间距为 48／32／16，列表缩进减小。插入表格时清理空白行空格，已有文字则保留整行并在下方插入；滑删红底覆盖移动圆角，时历红点位于边框上方。

记录与待办使用相同滑动删除；增加多选返回退出、合集列表、Markdown 表格粘贴、动态列宽与合集记忆，修复表格焦点和剪贴板冲突。保留表格下两次退格删除整表，取消双击删除行及选框列表。

时历在剩余 24 小时内显示圆角红点，倒计时归零立即删除，周期继续推进。数据导出自动复制并保存至授权的 inch-light 目录，旧导出保留 7 天；剪贴板与文件导入入口均位于设置页。

3.6.0 时历仅保留左滑删除；设置使用导出备份、粘贴导入和文件导入按钮。授权导出目录后每日自动备份完整数据，文件要求与手动导出一致，7 天后自动清理；Android 后台调度可能延迟，应用前台也会补查。
