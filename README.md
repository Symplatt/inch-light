# 一日千录

一日千录是一款 Android 本地应用，用于管理待办事项、书写笔记和查看时历倒计时。

当前版本：**3.13.7**（构建 86）。已发布版本及安装包见 [GitHub Releases](https://github.com/Symplatt/inch-light/releases)。

## 安装

普通 Android 手机优先下载 `app-arm64-v8a-release.apk`；其他设备按处理器架构选择对应安装包。同签名版本可直接覆盖安装并保留数据，更新前请在设置中导出备份。

3.13.6 与手机原有 3.13.5 签名不同，本轮已备份重装并恢复；后续使用同一签名覆盖安装。跨签名更新需先备份数据、隐藏合集、设置选择和连携配置，再重新安装并一并恢复；同签名版本可保留数据覆盖安装。

应用底部依次为 **待办、记录、时历、设置**，再次启动会恢复上次使用的模块；在模块名所在标题栏左右滑动可切换相邻模块，首尾不循环。

## 待办：安排事项和每日打卡

新建时可选择三种类型：

| 类型 | 用途 |
| --- | --- |
| 普通事项 | 记录需要完成的事情，可设置标签和截止时间 |
| 每日打卡 | 管理需要每天重复完成的事项 |
| 合集 | 把相关事项放在一起管理 |

- 设置截止时间时，可直接选择“今日截止”“明日截止”；“时间标蓝”可切换截止时间的显示颜色。
- 合集可以分别展开或折叠。“部分显示”先列出已显示合集，再列出隐藏合集，提供全选、全不选，可选择显示哪些合集；右滑合集也可将它隐藏，合集和其中事项仍然保留。
- “部分显示”按钮为浅灰时表示没有隐藏合集，较深灰时表示存在隐藏合集。
- 普通事项（含合集中的事项）自勾选完成满 7 天后自动删除；取消勾选会清除完成时间。应用启动、回到前台和运行期间检查；每日打卡仍按天重置。
- 可切换查看已完成事项。普通事项完成后播放 320 毫秒淡出；未固定合集的最后一项动画结束后，合集标题划线并淡出，再移除合集，完成事项仍保留。
- 长按普通事项的编辑窗口右上角可移动到任一合集或零散事项；移动保留内容、标签、截止时间和置顶／置底状态。
- 合集长按菜单可修改名称、一键完成或固定合集；固定合集在全部事项完成后仍保留，取消固定时若全部完成则移除合集。
- 合集和零散事项支持左滑删除，合集右滑隐藏；合集内单条事项保持原有操作，每日打卡可上下滑动删除。

## 记录：写笔记、整理内容和导出

### 查找与整理

笔记支持标题、标签和独立合集。搜索框可搜索标题与标签，应用会记住选择的合集。合集横滚栏滑回最左侧后，继续向右拖动较长距离并松手可打开合集列表；拖动有阻力，短滑会回弹。也可点击横滚栏末尾的列表按钮。列表窗口居中显示，高度不超过屏幕的 65%，超出内容在窗口内滚动。

设置中的“记录排序”可分别选择合集横滚栏与合集内笔记按最近编辑时间或名称排序；名称排序先英文、后中文，中文按拼音 A–Z 排列。笔记及搜索结果优先遵循置顶、置底。

右滑笔记可进入多选，批量移动或删除；多选状态下按系统返回键先退出选择。左滑删除的笔记在一分钟内可通过恢复入口找回。

### 书写与表格

标题支持加粗、斜体、删除线、高亮、下划线及行内代码语法即时渲染，选中复制和 Markdown 导出保留语法原文。

点击笔记正文进入编辑，可使用标题、加粗、斜体、下划线、黄色高亮、有序／无序／选框列表、行内代码、分隔线、上标和下标等格式。原有灰色高亮也显示为黄色；备份内容保持原样。行首行内代码灰底与正文左边缘对齐，文字保留内部留白；行中代码与相邻文字留出间隔，不插入实际空格。光标位于一段格式文本的首字之后、末字之前时，点击对应按钮可取消整段连续文本的该项格式，其他叠加格式保留。引用块内可使用有序、无序或选框列表，取消列表保留引用；引用内的列表符号和正文一起缩进，保留符号与正文间距，编号和圆点与引用正文同为灰色；引用内外的有序列表分别从 1 开始编号，Markdown 导出保持一致。在笔记标题末尾按换行键，可在正文开头插入空行并定位光标。

选框勾选后文字变灰并加删除线，切换勾选不改变行距及键盘状态。三种列表首项在行首退格时转为正文并保留文字；空首项、末项转正文，空中间项删除并拼接列表。

复制选区保留标题、列表、选框、引用和行内格式，粘贴到其他笔记时保留原有样式。粘贴 Markdown 文本时，二、三、四级标题对应笔记一、二、三级标题；空笔记中若以一级标题开头，该标题作为笔记标题，其余进入正文。粘贴支持列表、选框、引用、加粗、斜体、删除线、高亮、下划线、上下标、行内代码、代码块和表格；代码块内保留原文。支持插入表格和粘贴 Markdown 表格，最多 12 列。长按单元格可删除行、删除列或向右增加一列；删除最后一行或一列时会先确认是否删除整张表格。

表头菜单提供“复制表格”“删除表格”“下移一行”。复制结果为 Markdown；下移会在表格上方插入空白行。表格下连续两次退格也可删除整表。

### 快捷操作

在笔记浏览页打开“操作”，可对整篇笔记进行处理。快捷操作、连携操作及撤回后保持浏览状态，不自动弹出键盘；点击正文后进入输入模式，并保持光标所在位置可见。

| 操作 | 作用 |
| --- | --- |
| 标点管理 | 清理段首异常标点并补全正文、引用块和列表项；括号或引号内、前方已有句末符号时不补外层句号，并清理多余句号；补齐段首未闭合引号，保留行内代码和代码块 |
| 空格管理 | 完全跳过笔记标题及一至三级标题；清理其他行首空白，整理中英文间距，并将 `+`、`-`、`×`、`÷`、`/`、`@`、`\` 两侧空格统一为一个；删除行内代码外侧及内容首尾空格，保留代码内部空格 |
| 清除空行 | 去掉多余空白行 |
| 打乱无序列表 | 随机调整无序列表的条目顺序 |
| 标题升级／降级 | 调整标题层级，图标为 H 配上／下箭头 |
| 取消加粗 | 去掉正文及笔记标题的显式加粗，保留一至三级标题的固定粗体 |
| 首字母大写 | 处理英文首字母大小写；`agents.md` 转为 `Agents.md`，保留行内代码内容 |
| 勾选全部／清空勾选 | 批量切换选框列表状态 |

标点与空格管理始终显示，其余选项按笔记内容显示；有任意一至三级标题时同时显示升级与降级。无可用项时隐藏对应分组，“选框操作”排在第三组。连携编辑保留全部选项，不随内容隐藏。

菜单右上角的圆圈感叹号可查看简短介绍；取消加粗图标与其他图标保持相近面积和中心对齐。

**连携操作**可按指定顺序一次执行多项快捷操作：点击铅笔编辑，长按整行拖动；拖入“已选中”加入，拖回“未选中”移除，在已选中区域内拖动调整顺序。已选中项显示数字序号，未选中项显示小圆点，两组文字大小与行距一致。点击“保存”后，再点击菜单中的“连携操作”执行，整次操作可以一起撤回。长按浏览页魔法棒也可直接执行，完成横幅会注明快捷触发方式。

### 页面样式与长图

| 入口 | 影响范围 |
| --- | --- |
| 笔记浏览页的“页面设置” | 日常笔记样式，同时将修改的样式用于长图 |
| 导出长图页的“图片设置” | 仅调整本次及后续图片导出，不改变日常浏览样式 |

可调整字号、字间距、行间距、段间距、顶部／底部／两侧留白，以及是否显示编辑时间与字数。默认段间距为 10；“开头空两格”仅在图片设置中提供。设置改变显示效果，不改写正文。

笔记正文以灰白显示，高亮为淡黄色，浏览与导出长图一致；已有富文本的原始格式数据仍然保留。记录列表沿用浅灰底、白色搜索框和白色卡片；删除操作使用红色。

在导出菜单中可复制 Markdown 或导出长图。打开或关闭导出菜单、复制 Markdown 和从长图返回均保持浏览状态；复制的 Markdown 中，行内代码与相邻正文间各留一个空格，紧邻标点时不额外加空格。长图按手机实际像素密度生成无损 PNG，不因笔记较长而降低分辨率。

保存成功或唤起系统分享后，会记住本次图片设置并返回笔记浏览页；取消保存或导出失败时保留预览。系统分享是否最终发送成功，由所选应用处理。

## 时历：查看倒计时

时历用于查看事件倒计时，支持周期推进。剩余时间不足 24 小时会显示红点，导航图标同步显示红点；有新进入提醒范围的卡片时改为 `new`，进入时历后恢复红点。倒计时归零后删除当前项，周期按规则继续推进。卡片标题仅显示一行，超出部分用省略号代替；卡片仅支持左滑删除。

## 设置与备份

设置页依次显示事项顺序、记录排序、时历顺序与数据管理；事项和时历的选项保持纵向排列。

- **导出备份**：复制数据并保存备份文件。
- **文件导入**：从备份文件恢复数据。
- **粘贴导入**：通过剪贴板中的备份内容导入。

备份同时保存设置模块的选择、记录连携配置及页面／图片设置；旧备份不含这些字段时保留当前配置。文件和剪贴板均读取纯 JSON 备份，读取后弹出确认窗口；确认后恢复，取消不改数据。支持 UTF-8 BOM，文件选择器尝试打开既有备份目录。

首次导出时授权 `/storage/emulated/0/inch-light/` 文件夹，之后无需重复选择。授权后每天自动备份一次完整数据，超过 7 天的自动备份会被清理。后台时间由 Android 调度；应用启动、回到前台或跨日使用时也会补查。尚未授权目录时，请先手动导出一次。

设置页右上角可查看应用名称、版本、版权、开源许可及“快捷操作说明”；说明中列出左滑、右滑、长按等快捷操作。

键盘故障排查记录见 [Android 键盘排障](docs/android-keyboard-troubleshooting.md)。
