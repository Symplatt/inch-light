# 一日千录 · inch-light

轻量的 Flutter 待办、记录与时历应用。当前版本：**3.3.0**。

## 下载

从 [GitHub Releases](https://github.com/Symplatt/inch-light/releases/latest) 下载 Android 安装包。普通 Android 手机优先选择 `app-arm64-v8a-release.apk`，其他设备按处理器架构选择对应文件。

## 功能

- **待办**：普通事项、每日打卡、合集、标签、截止时间（支持一键「今日截止」「明日截止」至对应日期 23:59）、置顶与置底、完成状态及批量操作；右下角加号直接打开新建面板，在「普通事项」「每日打卡」右侧选择「合集」即可新建合集；日常打卡在最上方，零散事项默认在事项合集上方，可在设置中切换两者顺序，已完成视图使用相同顺序；新建和编辑普通事项、每日打卡及合集内事项时可按回车换行，换行随本地保存及备份保留；事项和合集卡片统一使用无阴影的浅灰细边框，合集内部事项以浅灰细线分隔；含未完成截止事项的合集优先排列，各组保留原顺序；事项与合集的绿色截止时间前以同色半透明圆角数字块显示剩余整天数（向下取整），24 小时内改为黄色实心闹钟，过期改为红色感叹号。 事项卡片自上而下显示正文、标签、截止时间；置顶与置底在右侧显示上／下箭头及顶部／底部短横线，卡片保持浅灰实线边框。
- **记录**：底部导航位于待办与时历之间；搜索栏下方横向切换合集，默认合集始终排第一并承接旧版零散笔记，其余合集按最近编辑排序，不支持合集置顶；横向合集始终左对齐，保留内容区两侧留白。右下角加号在当前合集中新建笔记，右上角依次为添加合集、批量导出；文件夹按钮新建合集，批量导出按钮将当前合集全部笔记复制为 Markdown，按显示顺序导出，篇与篇之间保留必要空行，保证每篇标题独占一级标题行，不插入分隔线。笔记标题为 17 号中等字重的深灰色单行文字（超出省略），时间、字数和小号浅灰标签同排；整个标签块与日期文字等高，标题和标签右侧固定预留位置图标区。笔记仅支持从右向左滑动直接删除，无需确认；删除后右上角出现恢复按钮，确认后恢复每条删除时间距今不足一分钟的笔记，每条独立计时；原合集已删除时恢复到默认合集。恢复窗口随本地保存跨重启保留，不延长时限。长按可置顶、置底、移动到其他合集或删除；置顶与置底互斥，右侧居中显示对应的上／下箭头，统一使用浅灰实线边框。长按合集打开名称编辑弹窗，自动聚焦输入框，保存按钮提交改名；左下角可删除合集，删除时可选择将笔记移入默认合集，或确认一并删除笔记；默认合集不能删除。默认页搜索同时匹配所有笔记的标题和标签，其他合集仅搜索当前合集，右侧小叉清空搜索。
- **笔记编辑**：顶部为 30 号标题、最近编辑时间与正文字数（不含标题、空白和格式标记，标点及完整表情各计 1 字）；非空标签以浅灰圆角块换行显示在统计与正文之间。标题、统计和标签随正文滚动。正文换行或移动光标时，页面自动跟随，保持光标位于键盘和语法栏上方。点击标题或正文编辑；键盘弹出时右上角依次显示撤回、取消撤回、标签和确定，确定保存并收起键盘。键盘上方格式栏首屏为 H₁、H₂、H₃、加粗、引用、有序列表、无序列表，恰好 7 个按钮，文字类图标按统一坐标绘制以保持对齐；向左滑动依次为选框列表、倾斜、删除线、分隔线、高亮、上标、下标、行内代码、表格、居中、左对齐、右对齐，正文默认左对齐，字色为稍浅的深灰；正文为 18 号，三级标题固定为更粗的字重，不受加粗开关影响；正文一级标题小于笔记标题。光标在笔记标题中时，加粗按钮切换整个笔记标题的字重。引用缩进为 10，引用线更细、文字更浅；有序／无序列表标记对齐正文实际首行基线，选框按首行高度居中，多行内容不影响标记位置，列表项间距比项内行间距稍大。仅正文之后的 H₁/H₂/H₃ 增加 12 的上间距，内容区首标题和连续标题保持紧凑。
- **Markdown 快捷输入**：行首输入 `# `、`## `、`### `、`- `、`1. `、`> ` 或 `[ ] `，会自动转为对应标题、列表或引用，支持手机软件键盘；输入 `**加粗**`、`*倾斜*`、`~~删除线~~`、`==高亮==`、`^上标^`、`~下标~` 或反引号包裹的行内代码也会自动渲染，后三项也可用格式栏按钮设置；正文标题导出时仍下移一级，例如 `## ` 对应导出的 `###`。
- **表格**：格式栏中点击表格按钮，默认 3 行 2 列，可输入行列数（初始 1–50 行、1–12 列，行数包含表头）。内容左对齐，表头加粗并略大于普通单元格、小于正文三级标题；在任意格中回车，会紧接当前行插入一行，并将光标移到新行的第一格。列数创建后固定。屏内表格总宽度固定，长内容列可借用短内容列的宽度，各列占满后恢复均分；宽表初始每列约 5 字宽，随内容增加至最多约 10 字宽（另含单元格内边距），可横向滚动；表格内容计入字数，支持保存、备份和 Markdown 表格导出。在表格下方空行按一次退格会选中并淡化表格，再按一次删除整个表格。
- **标签与发送**：标签图标在输入与观看模式中始终位于右起第二个；键盘收起时依次显示标签、发送。标签弹窗以空格分隔多个标签，自动去重，清空后可移除所有标签。发送可选择复制 Markdown 或导出长图，Markdown 包含标题与正文；长图同时包含最近编辑时间、正文字数和全部标签。长图预览右上角可保存 PNG 或调用系统分享；宽表会扩展图片宽度以包含所有列，过长内容自动降低像素倍率以保留全文。导出图标为向上箭头与托盘，合集批量导出额外显示两条内容线。复制 Markdown 时，笔记标题使用 Markdown 一级标题，正文 H₁/H₂/H₃ 导出为二/三/四级标题；高亮使用 `==内容==`，上标／下标使用 `^内容^`／`~内容~`（需要目标 Markdown 编辑器支持），行内代码保留反引号，选框使用 `- [ ]` / `- [x]`，居中与右对齐使用 HTML `div align`，其渲染取决于目标编辑器支持。
- **时历**：重要日期倒计时，以及每日、每周、每月、每年的周期事项；倒计时与周期均支持全天（以所选日期零点为目标，仅选择日期），两类列表可独立折叠，卡片支持左右滑动删除和长按编辑。卡片左侧显示名称与日期，周期和时刻以空格分隔，下一行单独显示下次日期；右侧以更宽列距显示三列倒计时，数字在上、单位在下，以细竖线分隔；剩余时间达到 24 小时显示年、月、日，不足 24 小时显示时、分、秒。
- **时间选择**：待办与时历共用日历日期选择和 24 小时数字时间输入。
- **设置**：选择事项合集/零散事项的显示顺序（合集选项排第一），选择倒计时/周期的时历顺序（默认倒计时在上），均自动保存；移除旧笔记顺序设置。小标题与时历使用相同缩进、字号、字重及间距；数据导入导出也在此处，底部版权署名为 Symplatt。
- **启动页面**：自动记住上次所在的待办、记录、时历或设置模块，下次启动回到该模块首页；首次安装进入待办。
- **本地数据**：自动保存；设置页可通过剪贴板导出和导入 JSON 备份。操作结果提示统一显示 1.5 秒。导入会覆盖备份中包含的对应数据区段，请先导出备份。

长按事项直接编辑，编辑标题右侧可置顶、置底或取消对应排序；长按合集打开操作菜单，可修改合集名称或批量完成、删除其中事项。删除合集会同时删除其中已完成和未完成的事项。事项合集和零散事项标题旁不再提供批量删除按钮。普通事项（含合集内事项）在完成满 7 天后自动清理，应用启动、恢复前台及运行期间会检查；每日打卡在日期变化时重置。

专注模块不提供。记录不包含思维笔记；输入短暂停顿后自动保存，返回、确定及切到后台时也会保存，空白新建页不会产生记录。旧版纯文本记录自动恢复为可编辑笔记，旧备份缺少记录或合集区段时保留现有对应数据。记录、标签、富文本及所属合集均随设置页 JSON 备份导入导出。外部剪贴板内容按纯文本粘贴。输入时，光标位于正文开头的空行，按一次退格会清除全部开头空行，让首个非空行上移，保留该行格式和后文空行；全篇空白时保持普通退格行为，可撤回本次清除。

## 平台支持

项目包含 Android、iOS、Windows、macOS、Linux 和 Web 工程；本次长图保存与分享接入 Android 系统文件选择器与分享面板，其他平台尚未接入。时历仅在应用内展示时间，不发送到期通知，不申请通知或精确闹钟权限。升级后首次打开会清理旧版时历提醒。

月末周期遇到较短月份时取当月最后一天，随后恢复原始日期；2 月 29 日的年度事项在平年使用 2 月 28 日。

## 本地开发

使用 Flutter **3.47.5**（Dart 3.13.4；最低 Flutter 3.44 / Dart 3.12）或兼容版本。Android 构建需要 JDK 17 与 Android SDK 36。

```sh
flutter pub get
flutter run
```

验证与构建：

```sh
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build apk --release --split-per-abi
```

编辑器使用 `vendor/flutter_quill` 的本地依赖，补丁说明见其 `PATCHES.md`；升级时需复核标题条件间距与回归测试。

更新图标后生成各平台启动图标：

```sh
dart run flutter_launcher_icons
```

## 项目结构

```text
lib/
  constants/   颜色和视觉常量
  models/      事项、笔记、合集和时历数据模型
  providers/   状态管理、本地持久化和数据导入导出
  screens/     待办、记录编辑、时历、设置与导航
  utils/       截止时间、周期计算和 Markdown 导出
  widgets/     共用控件
vendor/flutter_quill/  固定 11.6.0 的本地源码与标题间距、列表对齐补丁（保留 MIT LICENSE）
assets/        图标
test/          数据与界面回归测试
```

## 发布

从 `2.0.1` 开始重新计算版本。后续修改按语义化版本递增，日常修复默认递增补丁号；`pubspec.yaml` 的构建号始终递增。

每次发布同步更新 [CHANGELOG](CHANGELOG.md)、版本号和受影响的 README 内容，通过格式检查、静态分析与测试后推送代码和 `vX.Y.Z` 标签。GitHub Release 使用 CHANGELOG 对应版本内容，并附上 Android APK。

当前 Android 工程沿用开发签名，仅适用于自行安装；正式商店分发需要单独配置发布签名。不同签名的安装包无法直接覆盖安装，请先备份数据。
