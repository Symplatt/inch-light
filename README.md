# 一日千录 · inch-light

轻量的 Flutter 待办、记录与时历应用。当前版本：**3.9.0**。

## 下载

从 [GitHub Releases](https://github.com/Symplatt/inch-light/releases/latest) 下载 Android 安装包。普通 Android 手机优先选择 `app-arm64-v8a-release.apk`，其他设备按处理器架构选择对应文件。

## 使用

记录支持富文本、Markdown 表格粘贴、合集记忆及右滑多选；多选时系统返回先退出选择。笔记左滑删除与待办使用相同手势和动画，删除后一分钟内可恢复。表头悬浮菜单依次提供“复制表格”“删除表格”“下移一行”；复制使用 Markdown 格式，下移在表格上方插入一个空白行，表格下两次退格也可删除整表；不支持双击删行和选框列表。

语法栏支持下划线，位于高亮旁；分隔线位于上标、下标之前。插入表格时清除空行内空格，当前行有内容则保留整行并在其下方插入。正文之后一、二、三级标题上间距分别为 48、32、16，列表正文缩进为 24。

记录合集页可直接进入多选。表格单元格长按可删除行、删除列或向右增列，最多 12 列；删除最后一行或列时需确认删除整表。笔记浏览页“操作”提供清除空行、取消加粗、首字母大写、打乱无序列表、标题升级／降级、空格管理和去除异常标点，支持撤回，操作后保持键盘关闭。去除异常标点覆盖标题、段落、列表项与表格单元格的行首，保留引号、括号、书名号及句中标点。

导出长图时可在图片设置中调整字号、字间距、行间距、段间距、顶部／底部／两侧留白、段首空两格和编辑时间与字数显示，设置不修改原笔记。

待办卡片倒计时显示在标签上方。设置“数据管理”区域依次提供导出备份、文件导入、粘贴导入，每项附操作说明。

待办事项合集可整组折叠，通过“部分显示”勾选需要显示的合集；向右滑动合集可取消显示，合集及其中事项保留，可重新勾选恢复显示。设置页右上角可查看应用名称、版本、版权与开源许可。

时历卡片仅左滑删除。时历剩余 24 小时内显示红点，倒计时归零立即删除，周期继续推进。设置页直接提供剪贴板与文件导入；数据导出自动复制并保存到授权的 `/storage/emulated/0/inch-light/`，首次选择文件夹后无需重复确认，授权后每天自动备份一次完整数据，文件格式、命名与手动导出相同，超过 7 天自动清理。后台执行时间由 Android 系统调度，启动、回到前台和跨日使用时补查；未授权目录时需先导出一次。

完整更新见 [CHANGELOG](CHANGELOG.md)；兼容性说明见 [版本说明](docs/一日千录更新说明.md)。

## 项目结构

```text
lib/
  constants/   颜色和视觉常量
  models/      事项、笔记、合集和时历数据模型
  providers/   状态管理、本地持久化和数据导入导出
  screens/     待办、记录编辑、时历、设置与导航
  utils/       截止时间、周期计算和 Markdown 导出
  widgets/     共用控件
vendor/flutter_quill/  固定 11.6.0 的本地源码与标题间距、列表对齐补丁（保留 MIT LICENSE）
assets/        图标
test/          数据与界面回归测试
```

## 发布

从 `2.0.1` 开始重新计算版本。后续修改按语义化版本递增，未指定版本时由代理按实际变更决定主版本号、次版本号或修订号递增，用户指定时遵循用户要求；`pubspec.yaml` 的构建号始终递增。

每次发布同步更新 [CHANGELOG](CHANGELOG.md)、版本号和受影响的 README 内容，通过格式检查、静态分析与测试后推送代码和 `vX.Y.Z` 标签。GitHub Release 使用 CHANGELOG 对应版本内容，并附上 Android APK。

每次覆盖安装后，将该版本的更新日志单独保存为 Markdown 文档到 `D:\` 根目录；安装效果经用户审核通过后，再发布 GitHub Release 并交付同版本 APK。

当前 Android 工程沿用开发签名，仅适用于自行安装；正式商店分发需要单独配置发布签名。不同签名的安装包无法直接覆盖安装，请先备份数据。
