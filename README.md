# 一日千录

一日千录是一款 Android 本地应用，用于管理待办事项、书写笔记、查看时历倒计时和使用小工具。

当前版本：**3.18.0**（构建 128）。已发布版本及安装包见 [GitHub Releases](https://github.com/Symplatt/inch-light/releases)。

## 安装

普通 Android 手机优先下载 `app-arm64-v8a-release.apk`；其他设备按处理器架构选择对应安装包。同签名版本可直接覆盖安装并保留数据，更新前请在设置中导出备份。

3.13.6 与手机原有 3.13.5 签名不同，本轮已备份重装并恢复；后续使用同一签名覆盖安装。跨签名更新需先备份数据、隐藏合集、设置选择和连携配置，再重新安装并一并恢复；同签名版本可保留数据覆盖安装。

应用底部依次为 **待办、记录、时历、工具、设置**，再次启动会恢复上次使用的模块；在模块名所在标题栏左右滑动可切换相邻模块，首尾不循环。

## 待办：安排事项和每日打卡

新建时可选择三种类型：

| 类型 | 用途 |
| --- | --- |
| 普通事项 | 记录需要完成的事情，可设置标签和截止时间，卡片依次显示正文、倒计时、标签 |
| 每日打卡 | 管理需要每天重复完成的事项 |
| 合集 | 把相关事项放在一起管理 |

- 设置截止时间时，可直接选择“近日”“明日”“周日”，分别设置今天、明天或本周日的 23:59（一周从周一开始）；“时间标蓝”可切换截止时间的显示颜色。
- 合集可以分别展开或折叠。“部分显示”先列出已显示合集，再列出隐藏合集，提供全选、全不选，可选择显示哪些合集；右滑合集也可将它隐藏，合集和其中事项仍然保留。
- “部分显示”按钮为浅灰时表示没有隐藏合集，较深灰时表示存在隐藏合集。
- 普通事项（含合集中的事项）自勾选完成满 7 天后自动删除；取消勾选会清除完成时间。应用启动、回到前台和运行期间检查；每日打卡仍按天重置。
- 可切换查看已完成事项。普通事项完成后播放 320 毫秒淡出；未固定合集的最后一项动画结束后，合集标题划线并淡出，再移除合集，完成事项仍保留。
- 长按普通事项的编辑窗口右上角可移动到任一合集或零散事项；移动保留内容、标签、截止时间和置顶／置底状态。
- 合集长按菜单可修改名称、一键完成或固定合集；固定合集在全部事项完成后仍保留，取消固定时若全部完成则移除合集。
- 合集和零散事项支持左滑删除，合集右滑隐藏；合集内单条事项保持原有操作，每日打卡可上下滑动删除。

## 记录：写笔记、整理内容和导出

### 查找与整理

笔记支持标题、标签和独立合集。搜索框跨合集搜索标题与标签，按本合集、其他合集分组显示，其他合集的笔记逐条标明来源合集。点击空白处取消搜索焦点。应用会记住选择的合集。合集横滚栏滑回最左侧后，继续向右拖动较长距离并松手可打开合集列表；拖动有阻力，短滑会回弹。也可点击横滚栏末尾的列表按钮。合集列表与单条、批量“移动到合集”窗口共用尺寸和定位，高度不超过屏幕的 65%，超出内容在窗口内滚动。

设置中的“记录排序”可分别选择合集横滚栏与合集内笔记按最近编辑时间或名称排序；名称排序先英文、后中文，中文按拼音 A–Z 排列。笔记及搜索结果优先遵循置顶、置底。

右滑笔记可进入多选，批量移动或删除；多选状态下按系统返回键先退出选择。左滑删除的笔记在一分钟内可通过恢复入口找回。

### 书写与表格

标题支持加粗、斜体、删除线、高亮、下划线及行内代码语法即时渲染，选中复制和 Markdown 导出保留语法原文。

点击笔记正文进入编辑，可使用标题、加粗、斜体、下划线、黄色高亮、有序／无序／选框列表、行内代码、分隔线、上标和下标等格式。分隔线独占一行，在段落中间插入会分开上下两段；在其下方段首按一次退格，会连同分隔线所在行一起删除。原有灰色高亮也显示为黄色；备份内容保持原样。行内代码左右内间距各增加 3 像素；自动换行的代码文字与灰底保持一致内距，段首灰色圆角背景左边缘与其他段首文字左对齐，行中代码外侧间隔为 3 像素，不插入实际空格。光标位于一段格式文本的首字之后、末字之前时，点击对应按钮可取消整段连续文本的该项格式，其他叠加格式保留。引用块内可使用有序、无序或选框列表，取消列表保留引用；引用内的列表符号和正文一起缩进，保留符号与正文间距，编号和圆点与引用正文同为灰色；引用内外的有序列表分别从 1 开始编号，Markdown 导出保持一致。在笔记标题末尾按换行键，可在正文开头插入空行并定位光标。

选择一至三级标题会取消该段的显式加粗与斜体；光标位于列表中时，点击另一种列表按钮可转换整个连续列表，再次点击同类按钮将整个连续列表变回正文，保留缩进和引用。选框勾选后文字变灰并加删除线，切换勾选不改变行距及键盘状态。三种列表首项在行首退格时转为正文并保留文字；空首项、末项转正文，空中间项删除并拼接列表。

复制选区保留标题、列表、选框、引用和行内格式，粘贴到其他笔记时保留原有样式。粘贴 Markdown 文本时，二、三、四级标题对应笔记一、二、三级标题；空笔记中若以一级标题开头，该标题作为笔记标题，其余进入正文。粘贴支持列表、选框、引用、加粗、斜体、删除线、高亮、下划线、上下标、行内代码、代码块和表格；代码块内保留原文。支持插入表格和粘贴 Markdown 表格，最多 12 列。长按单元格可删除行、删除列或向右增加一列；删除最后一行或一列时会先确认是否删除整张表格。

表头菜单提供“复制表格”“删除表格”“下移一行”。复制结果为 Markdown；下移会在表格上方插入空白行。表格下连续两次退格也可删除整表。

### 快捷操作

在笔记浏览页打开“操作”，可对整篇笔记进行处理。快捷操作、连携操作及撤回后保持浏览状态，不自动弹出键盘；点击正文后进入输入模式，并保持光标所在位置可见。

| 操作 | 作用 |
| --- | --- |
| 标点管理 | 清理段首异常标点并补全正文、引用块和列表项；括号或引号内、前方已有句末符号时不补外层句号，并清理多余句号；补齐段首未闭合引号，保留行内代码和代码块 |
| 空格管理 | 完全跳过笔记标题及一至三级标题；清理其他行首空白，整理中英文间距，并将 `+`、`-`、`×`、`÷`、`/`、`@`、`\` 两侧空格统一为一个；删除行内代码外侧及内容首尾空格，保留代码内部空格 |
| 清除空行 | 去掉多余空白行 |
| 删除全文 | 保留笔记标题和标签，清空全部正文内容及格式，可撤回；点击后弹窗确认，长按满 1 秒直接执行；连携编辑中以红字显示 |
| 打乱无序列表 | 随机调整无序列表的条目顺序 |
| 标题升级／降级 | 调整标题层级，图标为 H 配上／下箭头 |
| 取消加粗 | 去掉正文及笔记标题的显式加粗，保留一至三级标题的固定粗体 |
| 首字母大写 | 处理英文首字母大小写；`agents.md` 转为 `Agents.md`，保留行内代码内容 |
| 勾选全部／清空勾选 | 批量切换选框列表状态 |

标点、空格管理与删除全文始终显示，其余选项按笔记内容显示；有任意一至三级标题时同时显示升级与降级。无可用项时隐藏对应分组，“选框操作”排在第三组。连携编辑保留全部选项，不随内容隐藏。

菜单右上角的圆圈感叹号可查看简短介绍；取消加粗图标与其他图标保持相近面积和中心对齐。

**连携操作**可按指定顺序一次执行多项快捷操作：点击铅笔编辑，长按整行拖动；拖入“已选中”加入，拖回“未选中”移除，在已选中区域内拖动调整顺序。已选中项显示数字序号，未选中项显示小圆点，两组文字大小与行距一致。点击“保存”后，再点击菜单中的“连携操作”执行，整次操作可以一起撤回。长按浏览页魔法棒也可直接执行，完成横幅会注明快捷触发方式。

### 页面样式与长图

| 入口 | 影响范围 |
| --- | --- |
| 笔记浏览页的“页面设置” | 日常笔记样式，同时将修改的样式用于长图 |
| 导出长图页的“图片设置” | 仅调整本次及后续图片导出，不改变日常浏览样式 |

可调整字号、字间距、行间距、段间距、顶部／底部／两侧留白，以及是否显示编辑时间与字数。默认段间距为 10；“开头空两格”仅在图片设置中提供。设置改变显示效果，不改写正文。

笔记正文以灰白显示，高亮为淡黄色，浏览与导出长图一致；已有富文本的原始格式数据仍然保留。记录列表沿用浅灰底、白色搜索框和白色卡片；删除操作使用红色。

在导出菜单中可复制 Markdown 或导出长图。打开或关闭导出菜单、复制 Markdown 和从长图返回均保持浏览状态；复制的 Markdown 中，行内代码与相邻正文间各留一个空格，紧邻标点时不额外加空格。图片设置可隐藏标签。长图按手机实际像素密度生成无损 PNG，不因笔记较长而降低分辨率。

保存成功或唤起系统分享后，会记住本次图片设置并返回笔记浏览页；取消保存或导出失败时保留预览。系统分享是否最终发送成功，由所选应用处理。

## 时历：查看倒计时

时历用于查看事件倒计时，支持周期推进。剩余时间不足 24 小时会显示红点，导航图标同步显示红点；有新进入提醒范围的卡片时改为 `new`，进入时历后恢复红点。倒计时归零后删除当前项，周期按规则继续推进。卡片标题最多显示两行，需要第二行时卡片自动增高，超出两行的部分用省略号代替；卡片仅支持左滑删除。

## 工具与工作日志

工具每行四个图标，按记录模块相同的名称排序规则排列，目前提供“吃什么”“工作日志”“上一次”“座下弟子”和“歪脖扣腚”。长按底部“工具”入口至少 1 秒可直接打开上次使用的工具。

设置中可勾选“进入模块自动跳转上次使用工具”，默认关闭；尚未使用过工具时显示工具列表，返回后仍可选择工具。开启后，点击底栏“工具”直接显示上次使用的工具；从工具切换其他模块后再次进入也会恢复，退出软件时处于工具模块则重启后直接恢复该工具。工具页面保留底部导航，左上角返回工具列表。该设置和上次使用的工具随完整备份保存。

工作日志页面支持音量键切换日期：音量降低进入下一天，音量增加进入上一天，最晚停在当天；按下切换一天，持续按住满 1 秒后开始每隔 0.5 秒切换一天，松开、离开页面或应用失去焦点后停止；退出工作日志后恢复音量键原有用途。

打开工作日志直接进入当天的日志页面，点击标题栏日期胶囊，通过年、月、日三列滚轮选择日期，也可在日期栏、栏目标题或空白处左右滑动切换相邻日期。以本地时间凌晨 4 点为分界，4 点前仍属于前一天，支持填写过去日期。

默认有学习、工作、其他三个固定栏目，点击栏目右侧加号新增文字事项，输入框从一行开始随内容增高，同栏目相邻事项之间显示细浅灰分隔线。点击事项可编辑，左滑事项可直接删除。右上角依次为一分钟复原、文本格式化和栏目设置。复原按钮仅在有一分钟内可复原的已删除事项时显示，复原保留原日期及栏目；文本格式化对当前日期事项执行空格管理和标点管理，不补句末句号，并移除每行末尾已有的句号。栏目设置弹窗可新增自定义栏目、拖动排序和左滑删除自定义栏目，长按自定义栏目名称可改名，三个基础栏目不可改名或删除；删除自定义栏目时，其所有日期事项转入“其他”。原技能事项自动合并到学习。工作日志内容和栏目随完整备份导出、导入，旧备份缺少工作日志时保留现有内容。

## 设置与备份

设置页依次显示事项顺序、记录排序、时历顺序、工具与数据管理；事项和时历的选项保持纵向排列。排序选项及工具选项字号为16，记录排序卡片内的两个小标题为16并加粗。

- **导出备份**：复制数据并保存备份文件。
- **文件导入**：从备份文件恢复数据。
- **粘贴导入**：通过剪贴板中的备份内容导入。

备份同时保存设置模块的选择、记录连携配置及页面／图片设置；旧备份不含这些字段时保留当前配置。文件和剪贴板均读取纯 JSON 备份，读取后弹出确认窗口；确认后恢复，取消不改数据。支持 UTF-8 BOM，文件选择器尝试打开既有备份目录。

首次导出时授权 `/storage/emulated/0/inch-light/` 文件夹，之后无需重复选择。授权后每天自动备份一次完整数据，超过 7 天的自动备份会被清理。后台时间由 Android 调度；应用启动、回到前台或跨日使用时也会补查。尚未授权目录时，请先手动导出一次。

设置页右上角可查看应用名称、版本、版权、开源许可及“快捷操作说明”；说明中列出左滑、右滑、长按等快捷操作。

键盘故障排查记录见 [Android 键盘排障](docs/android-keyboard-troubleshooting.md)。

### 吃什么

通过顶部菜单胶囊切换菜单，右侧从左到右为随机选菜、新增菜单、新增菜品。菜品按上次食用时间从远到近排列，未吃过的优先；点击右侧吃饭按钮记录本次食用并以短动画移到末尾。点击卡片查看完整食用时间列表，卡片及查看窗口支持长按编辑、左滑删除菜品。随机选菜按距上次食用的日历天数做 softmax，未吃过按 1 天计算，随机窗口突出菜名，底部“再换一道”重新选择，“不想吃了”关闭，“就决定是你了”确认后记入历史。卡片序号随当前排序从 1 重新编号。菜单与食用记录随完整备份保存。

吃什么图标使用 Ma Shan Zheng 毛笔字体的五字子集（SIL OFL 1.1），来源：https://github.com/google/fonts/tree/main/ofl/mashanzheng；许可证随应用打包。

### 歪脖扣腚

更新记录复用笔记编辑器，支持富文本、表格、快捷操作和连携，可复制Markdown。项目更新数据、连携配置和固定页面样式与记录模块独立。按项目管理更新记录，预置一日千录、额度启程、讯息聚合三个空项目。顶部胶囊切换项目，右上角分别新增项目和更新；长按胶囊或通过项目列表的操作菜单修改项目名称、删除项目。新增更新进入笔记编辑器，标题填写版本号；按日期从新到旧排列，点击编辑正文，长按修改版本号和日期，左滑删除。删除项目会一并删除其中的更新记录，并先确认。

### 座下弟子

右上角新增同门，填写姓名、性别和类型，入学年份及备注选填。性别胶囊默认♂，点击后圆球滑向右侧显示♀。类型提供硕士生、博士生、直博、硕博连读、其他。辈分可手动填写，或依据本人资料与对方入学年份自动计算师兄、师姐、师弟、师妹、同届，清空辈分后修改年份或性别可重新计算。卡片姓名固定预留五个汉字宽度，性别、年份、类型同排；按师兄师姐、同届、师弟师妹分组，每组未知年份优先，再按年份和名称排列。博士生按入学年份前推三年比较辈分，直博、硕博连读沿用填入年份，手填辈分优先。点击编辑、左滑删除。

### 上一次

按家务、健康、人际、宠物、设备、其他分类，记录事项的上次日期和已经过的自然日天数，按距上次天数从多到少排列。可选择单个日期或起止日期，起止日期按结束日期计算经过天数。新增窗口采用浅灰圆角输入框，分类与日期模式并排，起止日期按可用宽度并排或换行。右上角加号新增事项；点击卡片可“记为今天”或编辑，长按编辑、左滑删除。天数以本地午夜换日，应用回到前台时刷新。

三个新工具的数据随完整备份导出和导入；旧备份缺少对应工具时保留当前数据。
